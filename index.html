NeoGuesser

A daily fighting-game puzzle with two modes: name the stage from a zoomed-in image, then name the character from attribute clues. It covers 1,200+ stages and 448 characters across 15+ franchises. Answers are checked by serverless Cloudflare Pages Functions, so they never reach the browser. A Python pipeline scrapes MediaWiki/Fandom sources and pre-renders every zoom level for 978 scheduled puzzles under HMAC-signed filenames.
